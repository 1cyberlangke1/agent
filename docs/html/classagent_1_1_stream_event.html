详细描述

统一流事件。每个事件 = 类型判别 + 变体载荷，不用「一堆 optional 字段」。

流式语义：模型输出由若干 TextDelta / ThinkingDelta / ToolCallDelta 增量 组成，工具调用以 ToolCallEnd 收尾，Token 用量由 Usage 给出，流以 Done（完整响应）或 Error 终结。

消费方式：用 std::visit 访问载荷（与 ContentBlock 的 variant 风格一致）， 或用 type() 快速判别后 std::get 取具体载荷。
