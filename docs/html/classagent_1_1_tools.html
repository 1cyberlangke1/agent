详细描述

工具注册中心。纯静态类，不可实例化。

两种注册方式： 编译期: struct X : ToolBase<X> { ... }; + template struct agent::ToolBase<X>; （见 tools_reflection.hpp，schema 自动从反射生成） 运行时: Tools::reg(ToolInfo{...}, lambda);

线程安全：**COW 不可变快照**——写路径（reg）持 write_mutex_ 重建快照原子替换； 读路径（exec/list/get/resolve/names）只 atomic load 快照，**零锁**（单线程热路径零开销）。 exec 复制 shared_ptr<RegisteredTool> 后调用工具函数，不在持锁状态执行用户代码。
