详细描述

template<typename Provider, typename Behaviors = DefaultBehaviors>
class agent::Agent< Provider, Behaviors >

高层 Agent：多轮对话 + 工具调用的驱动核心。

职责：双层循环（内层对话、外层工具）、行为钩子（DefaultBehaviors，含压缩）、 steer/follow_up 插话、异步 abort、成本核算。持具体 Provider 类型（编译期绑定， 零虚函数）。默认不开放任何工具，须 set_tools 显式授权。

模板参数
Provider具体 LLM Provider 类型（如 AgnesProvider / OpenAIProvider）。
Behaviors行为集合，提供钩子 + 压缩策略，默认 DefaultBehaviors。
